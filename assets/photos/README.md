# Drop Aura's photos here

1. Copy the photo files into this folder.
2. Open `photos.js` and add one line per photo:

```js
{ file: 'decor-01.jpg', caption: 'Birthday stage, Porur' },
```

3. Reload the site. The "Prints from recent functions" section shows them as prints; tapping one opens it large.

Suggested names: `decor-01.jpg`, `photo-01.jpg`, `gifts-01.jpg`, `crafts-01.jpg`. Keep the longest side around 1600px and the file under 300 KB (WebP or JPG).

Until photos are added, the section shows a labelled placeholder row so the page never looks broken.

## Where the current photos and logo came from

The four photos already listed in `photos.js` (`signage.jpg`, `counter.jpg`, `hairclips-01.jpg`, `hairclips-02.jpg`) came from a client-supplied `photos.pdf` on 2026-09-08. That file also contained a "Stephen Raj, Event Planner/Coordinator" template slide, generic CREW/MEDIA ROLE/TEAM LEAD/ADMIN ID-badge mockups, three five-star-hotel-ballroom wedding stages, and an unbranded baby portrait — none of it carried the Aura name, so none of it was used.

The site's logo (`assets/aura-wordmark.png`, `aura-logo.jpg`, `favicon-32.png`, `apple-touch-icon.png`) is a perspective-corrected crop of Aura's own wooden wall sign, taken from a Google Maps photo of the shop.
